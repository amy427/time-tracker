# TimeLog 学习任务联动版

## 使用

在原 TimeLog 页面点击数学二、408、英语快捷活动，或「今日学习任务 → 一键进局」，同一个动作开始时间记录并关联任务。不要再同时运行 ZIP 中独立应用的计时器。

点击结束或切换到其他活动，上一段学习自动生成待结算局。不会弹窗阻止下一次记录。「学习战报」中补题数、独立正确题数、题号、阶段和下一步即可；可稍后填写，时间不重复计算。

「调整任务」设置科目、章节、完成标准和 8/15/25/40/60 分钟目标。当前局保留开局时的任务快照，配置修改从下一局生效。CS50P 在调整任务里配置，使用原快捷按钮进入。

「先停一下」结束当前计时，已有学习局保留、不扣分；「重新出发 · 8 分钟保底局」启动小目标。到点仅显示提醒，不自动停止、判定完成或补算后台时间。

## 数据边界

时间继续使用原有 Google 自动同步。任务与成果是本机 IndexedDB meta 数据，目前不会同步到 Google。页面已明确标记。既有独立应用的历史成果不会自动导入，也不内置其历史快照。

学习局以 TimeLog event UUID 关联，开始/结束与待结算局在同一个 IndexedDB 事务中保存。学习元数据不发送给 Apps Script，不修改原云端字段或 UUID/revision 协议。当前界面统计最近加载的学习局，不代表全部历史；点「查看更早学习局」加载更多。战报时长为撤离时快照，后续修正原始记录的最终时长以 TimeLog 为准。

阶段为用户自报证据，不自动判卷，不由时长兑换 XP。无题号、无独立正确题不能标为独立/复测通过；本版不实现积分商城或完整技能树。

「导出学习成果备份」可独立导出 JSON；导入只补充缺失的同 UUID 学习局，不覆盖已有局、不产生时间操作。设置页的「导出本地恢复副本」也包含学习成果。导出文件可能含学习内容，请自行保管，不要上传公开仓库。

## 发布

把更新包中的 frontend、scripts、tests、docs 合并到原项目相同目录，提交并推送原 GitHub 仓库，等待 GitHub Pages 工作流成功。无需改 Apps Script、重新 setup 或清空数据库。手机原网址刷新并关闭重开，等待新版离线缓存安装后再次打开。

不要在新域名或 localhost 累积正式记录：站点不同，本机数据库不同。预览测试使用隔离端口，未改手机数据。
